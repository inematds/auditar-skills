En resumen

Auditar Skills es un kit abierto para revisar las skills de tu agente, las carpetas con un archivo SKILL.md que Claude Code y Codex usan para hacer una tarea siempre de la misma manera. Incluye skill-creator-plus, una skill de RoboNuggets que revisa cada skill contra 46 reglas (la mayoría de la documentación oficial de Anthropic, algunas de la práctica), y una receta de INEMA en cinco pasos: correr el validador, tomar las cinco peores, generar un informe, probar con y sin la skill y activar un hook. Sirve para quien ya tiene varias skills y no sabe cuáles están rotas. Solo necesita Python 3.8 o más reciente, y ninguna skill cambia sin tu aprobación.

Qué es

Un espejo con receta

El skill-creator-plus original, más lo que INEMA agregó para usarlo en el día a día, incluido un validador que entiende skills en portugués y español.

📏 46 reglas con fuente

La mayoría viene de la documentación oficial de Anthropic (guía de skills, docs de Claude Code, guía de prompting de Fable 5 y Opus 5.5), con el enlace de cada una; algunas, como las familias NM y LB, vienen de la práctica del autor y están marcadas como consejo. 20 son solo de lectura, juzgadas por el agente.

⚡ Validador en un segundo

validate_skill.py en Python puro, sin instalar nada. Revisa la parte mecánica de una skill o de una carpeta entera e indica archivo y línea de cada problema. Solo lee; no modifica nada.

🧭 Receta INEMA

Cinco pasos para no auditar todo de una vez: validador, cinco peores, informe, prueba con y sin, hook. Con dos scripts nuevos: relatorio.py y hook_validar.py.

Cómo funciona

Del número a la corrección

Primero el validador mide; después el agente lee e informa; tú decides qué aplicar; la prueba lo demuestra; el hook lo sostiene.

Validador→ 5 peores→ Informe (AUDIT)→ Tú eliges→ Prueba con y sin→ Hook→ Validador de nuevo

FM · DS

Frontmatter que el YAML entiende; nombre y descripción dentro del límite, en tercera persona, diciendo cuándo usarla.

ST · CT

SKILL.md con menos de 500 líneas, referencias a un solo nivel, índice en archivos largos, nada de enlaces rotos ni TODO.

WF · SC

Checklist con "listo cuando" y línea de volver atrás; scripts que resuelven el error; paquetes con su línea de instalación.

NM · HK · TS · LB

Ajustes para los modelos 5.5, regla estricta en hook, pruebas con y sin la skill y una biblioteca sin dos skills peleando por el mismo pedido.

Requisitos previos

Qué necesitas

El validador y los scripts usan solo la biblioteca estándar de Python. El agente entra en el informe y en la corrección.

Python 3.8+

Linux, Mac o Windows. Nada que instalar con pip.

# verificar la versión
python3 --version

git

Para descargar el repositorio (o baja el ZIP desde GitHub).

git --version

Claude Code o Codex

Solo para los modos AUDIT, NEW y REFINE de la skill. El validador corre sin agente.

# las skills viven en
~/.claude/skills   # Claude Code
~/.agents/skills   # Codex
Guía de uso · paso a paso

La receta en seis comandos

Córrelos en orden. Los pasos 2 y 3 solo leen tus skills; el paso 4 solo edita después de que elijas.

1

Descarga el repositorio

Una carpeta en tu directorio personal. Los siguientes comandos se corren desde adentro.

git clone https://github.com/inematds/auditar-skills ~/auditar-skills
cd ~/auditar-skills
2

Corre el validador en todas

Una línea por skill: errores, avisos, notas y las reglas incumplidas. Código de salida 0 = sin errores, 1 = hay errores, 2 = no pudo correr.

python3 skill-creator-plus/scripts/validate_skill.py --all ~/.claude/skills   # Claude Code
python3 skill-creator-plus/scripts/validate_skill.py --all ~/.agents/skills   # Codex
3

Toma las cinco peores

relatorio.py ordena por errores y avisos y detalla las N peores, agrupando los hallazgos por regla. O elige las cinco que más usas.

python3 skill-creator-plus/scripts/validate_skill.py --all ~/.claude/skills --json \
  | python3 scripts/relatorio.py - --top 5 > relatorio.md
4

Instala la skill y pide el informe

El modo AUDIT lee la skill completa, marca cada regla (pasa, falla o n/a) con archivo y línea y solo edita lo que apruebes.

cp -r ~/auditar-skills/skill-creator-plus ~/.claude/skills/   # Codex: ~/.agents/skills/
# en Claude Code, en una sesión nueva:
"Audita la skill formato-curso-v2 contra las reglas de Anthropic. Solo el informe, no edites nada."
5

Prueba con y sin antes de borrar

Los modelos 5.5 suelen rendir mejor con menos instrucciones, pero solo una ejecución comparada demuestra que una línea es peso muerto. Arma dos copias y corre la misma tarea en cada una.

mkdir -p /tmp/teste-com/.claude/skills /tmp/teste-sem/.claude/skills
cp -r ~/.claude/skills/minha-skill /tmp/teste-com/.claude/skills/
cp -r ~/.claude/skills/minha-skill /tmp/teste-sem/.claude/skills/   # borra las líneas candidatas solo aquí
6

Activa el hook que valida al guardar

Es un ejemplo, no viene instalado. Cada vez que el agente guarde un SKILL.md, corre el validador; si hay errores, el agente recibe la lista y los corrige en el momento. Va en ~/.claude/settings.json.

{
  "hooks": { "PostToolUse": [ {
    "matcher": "Write|Edit",
    "hooks": [ { "type": "command",
      "command": "python3 ~/auditar-skills/scripts/hook_validar.py",
      "timeout": 60 } ]
  } ] }
}

Pruébalo antes de activarlo: código 0 = sin errores, 2 = errores listados. Detalles en docs/receita-inema.md (en portugués).

echo '{"tool_input":{"file_path":"'"$HOME"'/.claude/skills/minha-skill/SKILL.md"}}' \
  | python3 scripts/hook_validar.py; echo "código de salida: $?"
