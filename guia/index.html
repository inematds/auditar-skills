Em resumo

Auditar Skills é um kit aberto para conferir as skills do seu agente, as pastas com um arquivo SKILL.md que o Claude Code e o Codex usam para fazer uma tarefa sempre do mesmo jeito. Ele traz o skill-creator-plus, uma skill da RoboNuggets que confere cada skill contra 46 regras da Anthropic, e uma receita do INEMA em cinco passos: rodar o validador, pegar as cinco piores, gerar um relatório, testar com e sem a skill e ligar um hook. Serve para quem já tem várias skills e não sabe quais estão quebradas. Precisa só de Python 3.8 ou mais novo, e nenhuma skill muda sem você aprovar.

O que é

Um espelho com receita

O skill-creator-plus original, mais o que o INEMA acrescentou para usar no dia a dia, inclusive um validador que entende skills em português e espanhol.

📏 46 regras com fonte

Cada regra aponta para a página da Anthropic de onde veio (guia de skills, docs do Claude Code, guia de prompting do Fable 5 e do Opus 5.5). As que vêm da prática estão marcadas como conselho.

⚡ Validador em um segundo

validate_skill.py em Python puro, sem instalar nada. Confere a parte mecânica de uma skill ou de uma pasta inteira e diz arquivo e linha de cada problema. Só lê; não altera nada.

🧭 Receita INEMA

Cinco passos para não auditar tudo de uma vez: validador, cinco piores, relatório, teste com e sem, hook. Com dois scripts novos: relatorio.py e hook_validar.py.

Como funciona

Do número ao conserto

Primeiro o validador mede; depois o agente lê e relata; você decide o que aplicar; o teste prova; o hook segura.

Validador→ 5 piores→ Relatório (AUDIT)→ Você escolhe→ Teste com e sem→ Hook→ Validador de novo

FM · DS

Frontmatter que o YAML entende; nome e descrição dentro do limite, em terceira pessoa, dizendo quando usar.

ST · CT

SKILL.md abaixo de 500 linhas, referências a um nível, sumário em arquivo longo, nada de link morto ou TODO.

WF · SC

Checklist com "pronto quando" e linha de voltar; scripts que resolvem o erro; pacotes com linha de instalação.

NM · HK · TS · LB

Ajustes para os modelos 5.5, regra dura em hook, testes com e sem a skill e biblioteca sem duas skills disputando o mesmo pedido.

Pré-requisitos

O que precisa

O validador e os scripts usam só a biblioteca padrão do Python. O agente entra no relatório e na correção.

Python 3.8+

Linux, Mac ou Windows. Nada para instalar com pip.

# conferir a versão
python3 --version

git

Para baixar o repositório (ou baixe o ZIP pelo GitHub).

git --version

Claude Code ou Codex

Só para os modos AUDIT, NEW e REFINE da skill. O validador roda sem agente.

# skills ficam em
~/.claude/skills   # Claude Code
~/.agents/skills   # Codex
Guia de uso · passo a passo

A receita em seis comandos

Rode na ordem. Os passos 2 e 3 só leem as suas skills; o passo 4 só edita depois que você escolher.

1

Baixe o repositório

Uma pasta na sua casa. Os comandos seguintes rodam de dentro dela.

git clone https://github.com/inematds/auditar-skills ~/auditar-skills
cd ~/auditar-skills
2

Rode o validador em todas

Uma linha por skill: erros, avisos, notas e as regras violadas. Código de saída 0 = sem erro, 1 = há erros, 2 = não conseguiu rodar.

python3 skill-creator-plus/scripts/validate_skill.py --all ~/.claude/skills   # Claude Code
python3 skill-creator-plus/scripts/validate_skill.py --all ~/.agents/skills   # Codex
3

Pegue as cinco piores

relatorio.py ordena por erros e avisos e detalha as N piores, agrupando os achados por regra. Ou escolha as cinco que você mais usa.

python3 skill-creator-plus/scripts/validate_skill.py --all ~/.claude/skills --json \
  | python3 scripts/relatorio.py - --top 5 > relatorio.md
4

Instale a skill e peça o relatório

O modo AUDIT lê a skill inteira, marca cada regra (passa, falha ou n/a) com arquivo e linha e só edita o que você aprovar.

cp -r ~/auditar-skills/skill-creator-plus ~/.claude/skills/   # Codex: ~/.agents/skills/
# no Claude Code, numa sessão nova:
"Audite a skill formato-curso-v2 contra as regras da Anthropic. Só o relatório, não edite nada."
5

Teste com e sem antes de apagar

Os modelos 5.5 costumam ir melhor com menos instrução, mas só uma execução comparada prova que uma linha é peso morto. Monte duas cópias e rode a mesma tarefa em cada uma.

mkdir -p /tmp/teste-com/.claude/skills /tmp/teste-sem/.claude/skills
cp -r ~/.claude/skills/minha-skill /tmp/teste-com/.claude/skills/
cp -r ~/.claude/skills/minha-skill /tmp/teste-sem/.claude/skills/   # apague as linhas candidatas só aqui
6

Ligue o hook que valida ao salvar

Exemplo, não vem instalado. Toda vez que o agente salvar um SKILL.md, o validador roda; se houver erro, o agente recebe a lista e corrige na hora. Vai no ~/.claude/settings.json.

{
  "hooks": { "PostToolUse": [ {
    "matcher": "Write|Edit",
    "hooks": [ { "type": "command",
      "command": "python3 ~/auditar-skills/scripts/hook_validar.py",
      "timeout": 60 } ]
  } ] }
}

Teste antes de ligar: código 0 = sem erro, 2 = erros listados. Detalhes em docs/receita-inema.md.

echo '{"tool_input":{"file_path":"'"$HOME"'/.claude/skills/minha-skill/SKILL.md"}}' \
  | python3 scripts/hook_validar.py; echo "código: $?"
